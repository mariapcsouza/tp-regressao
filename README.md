# tp-regressao

Este repositório contém os arquivos referentes ao trabalho de regressão, cujo objetivo é analisar os preços de venda de casas na cidade de Windsor, no Canadá, em 1987.

## Organização do projeto

- `dados/`: banco de dados original e tratado.

- `imagens/`: gráficos e imagens.

- `resultados/`: tabelas e resultados das análises.

- `analise_casas.qmd`: relatório principal do trabalho.
